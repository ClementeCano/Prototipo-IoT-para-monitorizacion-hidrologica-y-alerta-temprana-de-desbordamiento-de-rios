Acerca del sistema

Dashboard de monitorización hidrológica, predicción y alerta temprana para municipios del entorno del río Ebro.
Volver al dashboard

Resumen funcional

El sistema integra datos hidrológicos de SAIH Ebro, previsión meteorológica de AEMET, persistencia en base de datos y un modelo predictivo por municipio. El objetivo es ofrecer una vista operativa que permita consultar nivel, caudal, lluvia, predicción a siete días, fiabilidad del modelo, descargas históricas y alertas personalizadas.

Arquitectura

  • Frontend web servido por FastAPI con comunicación en tiempo real mediante WebSocket.
  • Backend modular para usuarios, preferencias, alertas, ingesta SAIH/AEMET, predicción y exportación de históricos.
  • Persistencia en PostgreSQL para usuarios, sesiones, dispositivos push, descargas, predicciones y medias reales.
  • Tareas de fondo para refrescar datos, agregar medias diarias y completar la comparativa de fiabilidad.

Fuentes de datos

SAIH Ebro Nivel y caudal de estaciones hidrológicas. Se usa para el estado actual, las medias reales y la descarga histórica.
AEMET Previsión de lluvia y probabilidad de precipitación para apoyar la interpretación del riesgo.
PostgreSQL Datos persistidos de usuarios, sesiones, dispositivos, descargas, muestras horarias, medias diarias y predicciones.

Modelo predictivo

Cada municipio dispone de un modelo entrenado con series históricas de nivel, caudal y variables derivadas. La predicción se calcula sobre una ventana reciente de datos y genera valores estimados para los próximos siete días.

Para la comparativa de fiabilidad se guarda diariamente la predicción D+1 y se compara con la media real diaria persistida cuando está disponible. Las bandas de error de la gráfica usan el MAE histórico como estimación visible de incertidumbre.

Calidad y limitaciones

  • Un dato marcado como real procede del último refresco correcto de SAIH.
  • Un dato persistido procede de la base de datos cuando no se acaba de consultar la API.
  • Un último válido conserva el último valor fiable si la API no devuelve dato nuevo.
  • Si SAIH limita peticiones o no publica una señal, se informa al usuario y se reintenta automáticamente.
  • Las predicciones dependen de la calidad y actualidad de los datos de entrada; no sustituyen a fuentes oficiales de emergencia.

Métricas visibles

La pantalla principal muestra MAE, RMSE, número de muestras reales y fecha de última validación. Estas métricas se calculan con predicciones D+1 guardadas y valores reales diarios persistidos, por lo que crecerán de forma progresiva a medida que el sistema acumule días de uso.
